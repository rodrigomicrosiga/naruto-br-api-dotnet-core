# naruto-br-api-dotnet-core

Informações temporárias:

- Pacote System.Net.Http.Json via Nuget

Pontos:

- GetNarutoData: Um método básico que faz uma requisição GET para um endpoint da API do Naruto BR
- apiUrl: Substitua pelo endpoint específico que você deseja consumir
- HttpClient: Utilizado para realizar chamadas HTTP de forma eficiente

Config:

- Configure o arquivo launchSettings.json (na pasta Properties) para rodar a API em uma porta local. Certifique-se de testar a conexão com a API do Naruto BR.
